# Code

- `run_2022_full_analysis.py` — full January-December 2022 causal wavelet and baseline analysis from the preserved raw-data workflow.
- `verify_2023_metrics.py` — recomputes the reported 2023 out-of-sample evaluation metrics from the saved alert events and NOAA flare labels.

The 2023 verification script checks the reported scoring outputs; it does not regenerate the 2023 wavelet alerts directly from the raw NetCDF file.
