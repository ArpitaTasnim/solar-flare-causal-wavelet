# GOES datasets and reference catalogs

Large original NOAA/NCEI GOES scientific inputs are preserved as checksum-pinned assets in the [data-v1.0 release](https://github.com/ArpitaTasnim/solar-flare-causal-wavelet/releases/tag/data-v1.0) rather than committed to Git.

Local data layout:

```text
data/
  raw/
    2022/
      GOES_2022_FULL.zip
    2023/
      sci_xrsf-l2-avg1m_g16_y2023_v2-2-1.nc
  reference/
    2022/
      NOAA_CMX_reference_2022.csv
    2023/
      sci_xrsf-l2-flrpt_geo_y2023_v1-0-1.csv
  coverage/
    GOES_2022_full_year_coverage_summary.csv
    GOES_2023_coverage_summary.csv
```

Prepare the large GOES inputs with:

```bash
python code/prepare_goes_inputs.py
```

The committed reference catalogs and coverage summaries can be regenerated by the preparation/analysis scripts from the preserved inputs and NOAA/SWPC daily reports. See `docs/DATA_SOURCES.md` for provenance and the important 2022-vs-2023 catalog comparability note.
