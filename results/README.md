# Solar flare analysis results

This directory contains the compact numerical outputs reported or used in the paper.

## 2022
Includes pooled metrics, baseline comparison results, sensitivity/ablation tables, false-positive analysis, and the T=12 h mitigation experiment.

## 2023
Includes alert-event files, the frozen temporal out-of-sample comparison and pooled metrics for the reference T=6 h configuration and the pre-defined T=12 h mitigation setting.
